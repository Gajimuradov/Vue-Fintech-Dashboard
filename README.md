# Vue Fintech Dashboard

Компактный fintech dashboard для просмотра операций: пополнений, выводов, платежей и переводов. Проект сделан как портфолио-кейс для frontend internship, с акцентом не на «красивую витрину», а на реальный frontend-поток: API, состояние, фильтры, детализация операции, ошибки и тесты.

В интерфейсе можно найти операцию по клиенту или id, отфильтровать список по статусу и типу, отсортировать операции по дате или сумме, посмотреть дневную динамику и открыть карточку с историей изменения статуса.

## Стек

- Vue 3 и Composition API
- TypeScript
- Vite
- Pinia
- Vue Router
- MSW
- Vitest
- Playwright
- Scoped CSS

## Что внутри

- Dashboard со списком операций.
- Таблица с полями: `id`, `amount`, `currency`, `status`, `type`, `createdAt`, `userName`.
- Поиск по имени клиента и id операции.
- Фильтры по статусу и типу.
- Сортировка по дате и сумме.
- Аналитика по дневной динамике, статусам и типам операций.
- Валютные итоги отдельно по USD, EUR и GBP без смешивания в один условный показатель.
- Детальная страница операции с полной информацией и историей статусов.
- Loading, empty, no-results и error states.
- Mock API через MSW: приложение делает обычный `fetch('/api/transactions')`, а service worker возвращает тестовые данные.
- Искусственная задержка ответа и HTTP 503 сценарий для проверки unhappy path.
- Unit-тесты для фильтрации, сортировки, аналитики, валютных итогов и Pinia store.
- E2E-тест Playwright для сценария: dashboard -> фильтр -> detail page.

## Как устроен mock API

Данные лежат в `src/data/transactions.ts`, API-клиент находится в `src/api/transactionsApi.ts`, а MSW handlers описаны в `src/mocks/handlers.ts`.

В dev-режиме браузерный worker стартует перед монтированием Vue-приложения. В unit-тестах используется `msw/node`, поэтому Pinia store тестируется через тот же API-клиент, что и приложение.

Кнопка «Сымитировать сбой» отправляет запрос с параметром `scenario=error`, и MSW возвращает HTTP 503. Так можно показать error state без настоящего backend.

## Что показать на интервью

1. Открыть dashboard и показать список операций.
2. Найти операцию по имени клиента или id.
3. Отфильтровать список по статусу и типу.
4. Отсортировать операции по дате или сумме.
5. Показать аналитику: дневная динамика, статусы, типы и суммы по валютам.
6. Открыть детальную страницу операции и показать историю статусов.
7. Нажать «Сымитировать сбой» и объяснить error state через MSW.

## Что демонстрирует проект

- Умение проектировать Vue 3 приложение с Composition API и TypeScript.
- Разделение UI, API-слоя, store и чистой бизнес-логики.
- Работа с Pinia: loading, error, data, empty/no-results states и computed selectors.
- Реалистичный mocking на network boundary через MSW.
- Тестирование логики через Vitest и пользовательского сценария через Playwright.
- Продуктовое мышление для fintech UI: операции легко читаются, валюты не смешиваются, фильтры предсказуемы, а ошибка не ломает пользовательский опыт.
