# Vue Fintech Dashboard

Небольшой, но аккуратно собранный dashboard для финтех-операций. Проект сделан как портфолио-кейс для frontend internship: без лишнего визуального шума, с понятной таблицей, фильтрами, отдельной страницей операции и тестами для ключевых сценариев.

В интерфейсе можно быстро посмотреть пополнения, выводы, платежи и переводы, найти нужную операцию по клиенту или id, отфильтровать список по статусу и типу, а затем открыть карточку с деталями и историей изменения статуса. Сверху есть короткая аналитика: сколько операций в каждом статусе, как распределяется поток по типам и какой объем попадает в текущую выборку.

## Стек

- Vue 3 и Composition API
- TypeScript
- Vite
- Pinia
- Vue Router
- MSW
- Vitest
- Playwright
- Scoped CSS

## Что внутри

- Рабочая dashboard-страница со списком операций.
- Таблица с ключевыми полями: `id`, `amount`, `currency`, `status`, `type`, `createdAt`, `userName`.
- Поиск по имени клиента и id операции.
- Фильтры по статусу и типу операции.
- Сортировка по дате и сумме.
- Аналитика по статусам и типам операций: количество, доля и сумма в текущей выборке.
- Детальная страница операции с полной информацией и историей статусов.
- Mock API через MSW: приложение делает обычный `fetch('/api/transactions')`, а сервис-воркер перехватывает запрос и возвращает тестовые данные.
- Искусственная задержка ответа и сценарий ошибки для проверки loading/error состояний.
- Pinia store с loading, error, empty, no-results состояниями и computed selectors.
- Отдельная бизнес-логика для фильтрации, сортировки и аналитики.
- Unit-тесты для selectors, фильтров, сортировки, аналитики и store.
- E2E-тест Playwright для пути: открыть dashboard, отфильтровать список, перейти в детали.

## Как запустить

```bash
npm install
npm run dev
```

После запуска приложение будет доступно локально в браузере.

## Проверки

```bash
npm run test
npm run test:e2e
npm run typecheck
```
